# 🕌 رحلتي إلى إسطنبول

موقع لتنظيم رحلة إسطنبول. يعرض الأماكن السياحية والمطاعم والمحلات والفنادق ومحطات المواصلات، مقسّمة حسب الأحياء، في قائمة وعلى الخريطة.

## المزايا

- **الصفحة الرئيسية**: الأحياء مقسمة إلى الجانب الأوروبي والآسيوي، ولكل حي عدد أماكنه حسب النوع ونسبة ما زرتِه، مع خريطة لكل الأماكن.
- **صفحة الحي**: وصف الحي ومواصلاته العامة، وقائمة الأماكن مجمّعة حسب النوع (الاسم، النوع، العنوان، المواصلات)، مع خريطة. فيها بحث وفلترة حسب النوع، وخيار لإخفاء ما زرتِه.
- **تفاصيل المكان**: الصور، وطريقة الوصول (الوسيلة، الخط، أقرب محطة، دقائق المشي)، وزر للفتح في Google Maps، وزر للاتجاهات بالمواصلات العامة.
- **خطة الأيام**: توزيع الأماكن على أيام الرحلة وترتيبها، مع خريطة مرقّمة لمسار كل يوم.
- **علامة «زرته» ✓** لكل مكان.
- **إضافة وتعديل** الأماكن والأحياء والأنواع من داخل الموقع، مع رفع صور تُضغط تلقائياً.
- كل التعديلات تُحفظ في **local storage** في المتصفح.

## التشغيل محلياً

يستخدم الموقع ES modules، لذلك يجب فتحه عبر خادم محلي (لا يعمل بالضغط المزدوج على الملف):

```bash
python3 -m http.server 8000
```

ثم افتحي `http://localhost:8000`.

## النشر على GitHub Pages

1. ادمجي هذا الفرع في `main`.
2. من صفحة المستودع على GitHub اذهبي إلى: **Settings ← Pages**.
3. في **Source** اختاري `Deploy from a branch`، ثم الفرع `main` والمجلد `/ (root)`، واضغطي **Save**.
4. بعد دقيقة أو اثنتين يصبح الموقع متاحاً على: `https://hadeel-harbi.github.io/visit-istanbul/`

## إضافة بياناتك

### من داخل الموقع
اضغطي «+ مكان» في الأعلى. للحصول على الإحداثيات من رابط مختصر (`maps.app.goo.gl`) افتحي الرابط في Google Maps، ثم اضغطي مطولاً على المكان وانسخي الإحداثيات (مثل `41.0086, 28.9802`) والصقيها. ويمكنك بدلاً من ذلك الضغط على الخريطة داخل النموذج لتحديد الموقع.

### من ملف البيانات `data/seed.js`
هذا الملف يُحمَّل عند أول فتح للموقع. شكل المكان الواحد:

```js
{
  id: 'seed-ayasofya',             // معرّف فريد يبدأ بـ seed-
  name: 'آيا صوفيا',               // الاسم بالعربي
  nameLocal: 'Ayasofya',           // الاسم الأصلي (اختياري)
  typeId: 'attraction',            // attraction | restaurant | cafe | shop | park | hotel | station | other
  districtId: 'sultanahmet',       // معرّف الحي
  address: '...',                  // اختياري
  lat: 41.00858, lng: 28.98017,    // الإحداثيات
  mapsUrl: 'https://maps.app.goo.gl/...', // اختياري
  hours: '', price: '', notes: '', // اختياري
  transport: { mode: 'tram', line: 'T1', station: 'Sultanahmet', walkMinutes: 4, note: '' },
  day: 1,                          // اليوم في الخطة (اختياري)
}
```

قيم `transport.mode`: `tram`, `metro`, `marmaray`, `funicular`, `ferry`, `bus`, `walk`, `taxi`.

بعد إضافة أماكن جديدة **غيّري رقم `version`** في أعلى الملف. عندها يضيف الموقع الأماكن الجديدة فقط، ولا يمسح تعديلاتك أو صورك.

> البيانات الحالية في الملف **تجريبية** بإحداثيات تقريبية. استبدليها ببياناتك.

## تحديث الموقع وذاكرة المتصفح المؤقتة

يحتفظ المتصفح بنسخ من ملفات الموقع. لذلك عند تعديل أي ملف JavaScript أو CSS أو ملف البيانات، **زيدي رقم `?v=` في `index.html`** في كل المواضع (في import map، وفي `js/app.js`، وفي `css/style.css`)، حتى يحمّل المتصفح الملفات الجديدة.

يبقى `index.html` نفسه مخزناً في المتصفح حتى 10 دقائق على GitHub Pages، فقد يتأخر ظهور التحديث قليلاً. للتحديث الفوري اضغطي `Ctrl+Shift+R` (أو `Cmd+Shift+R` على الماك).

## ملاحظات عن التخزين

- البيانات محفوظة في المتصفح نفسه فقط. لن تظهر تعديلاتك على جهاز آخر، وتُفقد إذا مسحتِ بيانات المتصفح.
- مساحة local storage حوالي 5 ميغابايت، أي ما يكفي لحوالي 30 إلى 40 صورة مضغوطة. صفحة **الإعدادات ⚙️** تعرض المساحة المستخدمة.

## البنية

```
index.html          الصفحة الوحيدة
css/style.css       التصميم
js/app.js           التوجيه بين الصفحات والأزرار
js/store.js         البيانات و local storage
js/views.js         الصفحات: الرئيسية، الحي، الأيام، الإعدادات
js/components.js    البطاقات والنوافذ والنماذج
js/map.js           الخريطة (Leaflet + OpenStreetMap)
js/utils.js         أدوات مساعدة (استخراج الإحداثيات، ضغط الصور...)
data/seed.js        البيانات الأولية
vendor/leaflet/     مكتبة Leaflet 1.9.4
```
